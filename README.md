

# BT2 - Personal Profile Card

## 1. Giới thiệu

Đây là dự án bài tập cá nhân BT2, được xây dựng bằng React và Vite.

Ứng dụng hiển thị thẻ giới thiệu cá nhân, bao gồm:
- Họ và tên.
- Lớp học.
- Sở thích.
- Liên kết GitHub.

## 2. Công nghệ sử dụng

- React
- JavaScript
- Vite
- HTML
- CSS

## 3. Cài đặt và chạy dự án

Clone dự án về máy:

```bash
git clone https://github.com/hoanggia776123-svg/bt2-react-vercel.git
```

Di chuyển vào thư mục:

```bash
cd bt2-react-vercel
```

Cài đặt thư viện:

```bash
npm install
```

Chạy ứng dụng:

```bash
npm run dev
```

## 4. Giải thích mã nguồn

Dự án sử dụng component `ProfileCard` để hiển thị thông tin cá nhân. Dữ liệu được lưu trong một object JavaScript và hiển thị bằng JSX.

- Mục đích: Hỗ trợ tạo cấu trúc component React, viết CSS và giải thích một số đoạn mã.
